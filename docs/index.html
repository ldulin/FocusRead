FocusRead reads a paper to you one sentence at a time. Click a sentence to hear it, click again to stop; the sentence being read is highlighted, and each word lights up as it is spoken.

Everything happens on your device - the file is never uploaded. Only the sentences you ask to translate leave the machine, and only to the provider you picked in Settings.

This is the reader only. To use FocusRead on web pages as well you need the Chrome extension, which browsers on phones cannot run - source and install instructions.
